About YouTube Music Recommender

This is a music recommendation system that uses YouTube as a data source. It analyzes audio features from YouTube videos to generate personalized recommendations.

Project by Julio Soldevilla

How it works:
  • Extracts audio features from YouTube music videos
  • Uses machine learning to find similar songs
  • Supports diversity control to get varied recommendations
  • Limits recommendations per artist to avoid repetition
